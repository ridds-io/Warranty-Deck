# Warranty Deck

Never lose a receipt again. Warranty Deck is your personal digital vault for managing warranties, receipts, and product information.

**🌐 Try it now**: [https://warranty-deck.vercel.app/](https://warranty-deck.vercel.app/)

## 🎯 What is Warranty Deck?

Warranty Deck solves a universal problem: losing receipts and missing warranty claims. With an intuitive dashboard, powerful analytics, and smart notifications, you'll always know what you own, what's covered, and when your warranties expire.

## ✨ Key Features

### 🏠 **Dashboard**
- Quick overview of your total receipts, active warranties, and pending alerts
- Real-time list of warranties expiring soon
- Recent receipts for quick access
- Visual spending patterns chart
- One-click navigation to detailed views

### 🔐 **Vault**
- Centralized storage for all your receipts and documents
- Search across all stored items instantly
- Filter by store categories (Electronics, Groceries, Clothing, etc.)
- Upload receipt images and documents
- Smart receipt scanning with OCR technology
- Clean, organized card-based browsing

### 📊 **Analytics**
- Track your total spending at a glance
- Calculate average receipt value
- See spending trends by day of the week
- Analyze spending by product category with visual charts
- Monitor all active and expiring warranties

### ⏰ **Warranty Management**
- View detailed warranty information and coverage details
- Real-time countdown timers for expiring warranties
- Status tracking (Active, Expiring Soon, Expired)
- Link warranties to original purchase receipts
- Never miss an important claim deadline again

### 💰 **Reimbursement Tracking**
- Organize work and medical receipts for expense claims
- Track return deadlines and reimbursement windows
- Export receipts when submitting claims

### 🎨 **Memorabilia**
- Save meaningful receipts as memories, not just expenses
- Keep records of special purchases and occasions

### 🤖 **Chatbot Assistant**
- Ask questions about your warranties and products
- Get instant answers about warranty coverage and terms
- Get help navigating your receipt library

### ⚙️ **Settings**
- Switch between light and dark themes
- Configure notification preferences
- Manage warranty expiry alerts
- Set return deadline reminders
